# Course: Databases

Relational databases, SQL, PostgreSQL, migrations, ORMs, indexes, transactions, pooling and backups, for a complete beginner. Every module has an everyday
analogy, diagrams, line-by-line explanations, a hands-on exercise with **real captured output**, a quiz and links to the official documentation.

**Prerequisite:** none. The exercises run in throw-away Postgres containers, so [Docker 01](../docker/01-images-and-containers.md) is a good first read.
Back to the [course index](../README.md). Read each module next to [Lab 04](../../labs/04-database.md).
