# Course: Docker

How containers work, from zero, for a complete beginner. Every module has an everyday analogy, diagrams, line-by-line
explanations, a hands-on exercise with **real captured output**, a quiz and links to the official documentation.

**Prerequisite:** Docker Desktop installed ([Lab 00](../../labs/00-setup.md)). No other knowledge.
Back to the [course index](../README.md).
