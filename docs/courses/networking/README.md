# Course: Networking

IP addresses, ports, DNS, HTTP, NAT, subnets, firewalls and TLS, for a complete beginner. Every module has an everyday
analogy, diagrams, line-by-line explanations, a hands-on exercise with **real captured output**, a quiz and links to the
official documentation.

**Prerequisite:** none. The exercises use Docker, so [Docker 01](../docker/01-images-and-containers.md) is a good first read.
Back to the [course index](../README.md).
